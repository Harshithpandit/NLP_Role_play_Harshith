# Smart News Classification & Summarization System

An NLP-based startup MVP that classifies news articles into categories and generates extractive summaries using TF-IDF, Logistic Regression, and SpaCy.

## Features
- News Classification
- Extractive Summarization
- Streamlit Deployment

## Tech Stack
- Python
- Scikit-learn
- SpaCy
- Streamlit
- NLP

## Accuracy
~90% on AG News Dataset
